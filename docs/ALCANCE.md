# Alcance de Brailux

## Alcance actual

Brailux se concentra en una experiencia introductoria para conocer y practicar fundamentos del sistema Braille.

La versión web contempla:

- historia y función del Braille;
- signo generador de seis puntos;
- numeración 1-2-3 y 4-5-6;
- lógica de formación de las primeras series del alfabeto;
- alfabeto Braille integral en español;
- números y signos diferenciadores;
- lectura y escritura;
- comparación entre escritura con pauta y punzón y escritura positiva;
- ejercicios de reconocimiento;
- conversor didáctico básico;
- contenidos sobre Braille y tecnología;
- portal con acceso a Aprende, Practica, Ranking XP y futura descarga de la app;
- accesibilidad compartida con Neuronova Apps.

## Alcance de aprendizaje

La experiencia se organiza alrededor de cuatro rutas principales:

1. **Aprende**: fundamentos, estructura y teoría.
2. **Practica**: actividades de reconocimiento y construcción.
3. **Progreso**: base futura para XP, logros y seguimiento.
4. **Tecnología**: aproximación a herramientas Braille digitales.

## Límites actuales

Brailux no pretende cubrir todavía de forma completa:

- alfabetización táctil formal;
- matemáticas Braille avanzadas;
- signografía científica especializada;
- musicografía Braille;
- fonética;
- estenografía;
- metodologías específicas de intervención educativa.

Estos contenidos solo se incorporarán cuando puedan desarrollarse con respaldo técnico suficiente.

## Web y aplicación

La web funciona como espacio de conocimiento, práctica y presentación del proyecto.

La aplicación móvil podrá ampliar progresivamente la experiencia con progreso persistente, niveles, XP, logros, ranking, actividades adicionales y funcionamiento optimizado para dispositivos móviles.

## Criterio de crecimiento

Cada ampliación debe mantener tres condiciones:

- utilidad real para el usuario;
- precisión del contenido Braille;
- accesibilidad y claridad de interacción.
